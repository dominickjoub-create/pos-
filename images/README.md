# Image assets

Drop real photos here using these exact filenames — the site references them
directly and shows styled placeholders until they exist:

- `about-hemza.jpg`   — Hemza / interior portrait (~640×760)
- `gallery-1.jpg` … `gallery-5.jpg` — cuts & interior shots (~600×700)
- `og-cover.jpg`      — 1200×630 social share image

All are optional to launch: missing images degrade gracefully to placeholders.
